# `dsh-at-file` Plugin Guide

This folder contains setup and installation instructions for the **`@file` Mention Plugin** (`dsh-at-file`).

## 📌 Upstream Repository
* Original Repository: [`github:omdsh-dev/dsh-at-file`](https://github.com/omdsh-dev/dsh-at-file)

## 💡 Functionality
* Enables `@file` autocomplete mentions directly inside the chat input box.
* Typing `@` followed by a filename pops up a search menu to mention and attach workspace files/directories to your prompt.

## 🚀 Installation

```bash
dsh plugin --profile web add github:omdsh-dev/dsh-at-file
```
